# ScreenCampaigns

Kampagnen-Übersicht als Kartenraster (3 Spalten Desktop, 2 Tablet, 1 mobil) aus `CampaignCard`.

**Kopf:** Titel + Zusammenfassung · `Button ai` „Kampagne vorschlagen“ · `Button primary` „Neue Kampagne“. Darunter Segment-Tabs nach Kampagnenstatus mit Anzahl, Suche, Sortierung.

**Letzte Kachel** ist immer „Neue Kampagne“ (gestrichelt) – so ist der nächste Schritt auch bei wenigen Kampagnen sichtbar.

**Leer:** `EmptyState first-use` „Noch keine Kampagne – eine Kampagne bündelt Beiträge zu einem Ziel, z. B. ‚30 Anfragen im Frühjahr‘.“ mit KI- und Primäraktion. **Filter ohne Treffer:** `EmptyState no-results`.
