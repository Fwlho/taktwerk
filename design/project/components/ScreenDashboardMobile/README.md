# ScreenDashboardMobile

Dashboard und Kalender auf dem Smartphone (390×844, einspaltig, Seitenrand `space-4`, untere Navigation `MobileNav`).

**Dashboard mobil:** Begrüßung `text-h1` · Freigabe-Karte (nur wenn offen) mit großem Primär-Button – der wichtigste Tipp liegt im Daumenbereich · zwei `KpiTile` ohne Sparkline · „Heute & morgen“ als Liste aus `CalendarEntry` · eine KI-Idee.

**Kalender mobil:** Monatsraster als Punktansicht (ein 6px-Punkt pro Kanal in Kanalfarbe, max. 3) · Tippen auf einen Tag zeigt darunter dessen `PostCard`s · Segment-Tabs Monat/Woche/Liste · Wischen links/rechts wechselt den Monat.

**Leer:** „Heute & morgen“ ohne Einträge → Satz „Heute ist nichts geplant.“ + Ghost-Button „Beitrag anlegen“.
